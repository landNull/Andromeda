# Open the keys menu

Open the grouped shortcut menu.

## Steps

1. Type `andromeda help-keys` or `help-keys`.
2. Choose a category.
3. Choose a key.
4. The matching page from the docs satellite opens.
5. Press `q` to return.

## Result

The keys are visible, grouped, and linked to the living pages.
